## 📖 Introduction

**Jesus Client Deluxe** is a next-generation, high-performance utility client for **Minecraft 1.21**.

Built with a **fully customized core**, this client focuses on **stability, performance, and precision gameplay**.  
Every system has been redesigned and optimized to deliver a smooth and powerful experience, especially for competitive and anarchy environments.

---

## ✨ Key Features

Jesus Client Deluxe is built around speed, control, and efficiency:

### ⚔️ Combat
* **KillAura:** Advanced targeting with customizable timing and accuracy
* **AutoCrystal:** Fast placements, smart damage calculation, optimized latency
* **Criticals:** Reliable critical hit system based on movement mechanics

### 🚀 Movement & Utility
* **Speed / Fly:** Smooth and configurable movement systems
* **PacketFly:** Stable and optimized phasing system
* **Scaffold:** Safe-walk, tower, and advanced placement logic

### 🖥️ Performance & UI
* **Modern ClickGUI:** Clean, fast, and fully customizable interface
* **FPS Optimization:** Lightweight rendering and performance-focused code
* **HUD Editor:** Fully draggable and customizable HUD system

## 🛠 Installation Guide

1. **Download:** Get the latest `.jar` from the [Releases](https://github.com/EnvalArchery/Jesus-Client-Deluxe/releases/tag/JesusClient)
2. **Install Loader:** Make sure you have the correct **Fabric** or **Forge** version for Minecraft 1.21
3. **Move File:** Put the `.jar` into your `.minecraft/mods` folder
4. **Launch:** Start Minecraft and enjoy
