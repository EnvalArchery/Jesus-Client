## About

Jesus Client Deluxe is a lightweight and performance-focused client for Minecraft 1.21.  
It is designed to provide useful modules with smooth performance and a simple interface.

---

## Features

- Combat modules (KillAura, AutoCrystal, Criticals)
- Movement modules (Speed, Fly, Scaffold)
- ClickGUI and HUD editor
- Optimized for performance

---

## Installation

1. Download the latest `.jar` from Releases  
2. Install Fabric Minecraft 1.21  
3. Put the file into `.minecraft/mods`  
4. Launch the game
