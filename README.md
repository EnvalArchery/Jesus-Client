## 📖 Introduction

**Jesus Client Deluxe** is a next-generation, high-performance utility client for **Minecraft 1.21**. Built upon the powerful foundation of **Thunderhack-Recode**, this fork is specifically optimized for the latest game version, offering unmatched stability, redesigned visuals, and lethal efficiency.

We took the best parts of Thunderhack and enhanced them with custom modules, tighter bypasses, and a focus on raw performance.

## ✨ Key Enhancements & Features

Unlike standard clients, Jesus Client Deluxe focuses on precision and power:

### ⚔️ Advanced Combat
* **Optimized KillAura:** Custom timing modes for 1.21 combat mechanics.
* **Enhanced AutoCrystal:** Faster placements, smarter targeting, and lower latency.
* **Custom Criticals:** Exploit 1.21 movement physics for guaranteed critical hits.

### 🚀 Movement & Utility
* **Speed/Fly Bypasses:** Tuned for popular 1.21 anti-cheats.
* **PacketFly:** Redesigned for smoother and more reliable phasing.
* **Scaffold:** Highly customizable with tower and safe-walk options.

### 🖥️ Performance & UI
* **Modern ClickGUI:** A sleek, intuitive, and highly customizable interface.
* **FPS Boost:** Optimized code rendering ensures high performance even during intense combat.
* **Hud Editor:** Drag-and-drop HUD elements to create your perfect setup.

## 🛠 Installation Guide

1.  **Download:** Grab the latest `.jar` file from the [Releases]([link-to-your-releases-here](https://github.com/EnvalArchery/Jesus-Client-Deluxe/releases/tag/JesusClient)) tab.
2.  **Dependencies:** Ensure you have the correct **Fabric** or **Forge** loader installed for Minecraft 1.21.
3.  **Placement:** Drop the downloaded `.jar` file into your `.minecraft/mods` folder.
4.  **Launch:** Start Minecraft and enjoy the Deluxe experience.
